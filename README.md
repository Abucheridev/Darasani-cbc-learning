# Darasani — Your Learning Companion

A Kenyan CBC learning platform for Grades 6–9.

The application foundation is being built with React, TypeScript, Vite and Supabase. The repository will hold the student, teacher, parent and administration experiences, learning resources, assessments, subscriptions, AI tutor and offline capabilities.

## Status
Initial project setup. Features are implemented and tested in stages before public launch.

## Security
Never commit API secrets, Supabase service-role keys, Gemini keys or Safaricom Daraja credentials. Keep privileged secrets in Supabase Edge Function secrets. Apply Row Level Security to every exposed database table.
